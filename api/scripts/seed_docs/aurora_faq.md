# Aurora Analytics — FAQ

> Fictional FAQ used as sample corpus for the RAG demo.

**Can I try Aurora before paying?**
Yes. Every new workspace starts with a 14-day free trial of the Business plan, with no
credit card required. At the end of the trial the workspace drops to the Starter plan unless
you upgrade.

**How many people can use one workspace?**
The Starter plan supports up to 5 users. The Business plan supports up to 100 users. For
more than 100 users, contact sales about the Enterprise plan.

**Does Aurora support single sign-on?**
SAML single sign-on is available on the Business and Enterprise plans. It is not available
on the Starter plan.

**Can I export my data?**
Yes. Any Viewer, Editor, or Admin can export a dashboard table to CSV or Excel. Full
workspace exports, including all dashboards and data source definitions, are available to
Admins from Settings → Export.

**What happens to scheduled reports if a data source fails to refresh?**
If a data source fails its scheduled refresh, Aurora sends the last successfully cached data
in the report and flags the report with a stale-data warning. After three consecutive failed
refreshes, Aurora emails the workspace Admin.

**Is there a mobile app?**
There is no native mobile app. Dashboards are responsive and can be viewed in a mobile
browser, but editing requires a desktop browser.
